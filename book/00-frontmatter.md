# คำนำ

ARRA Relic Scan เป็นเครื่องมือที่ทำงานเดียว ค้นหาทรานสคริปต์ของเอเจนต์ AI ทุกไฟล์ในเครื่อง แล้วเก็บเป็นดัชนีที่ถามได้ ไม่ว่าจะเป็น Claude Code, Codex, omp หรือตัวอื่น ผลลัพธ์คือไฟล์ Parquet หนึ่งไฟล์ต่อหนึ่งเดือน อยู่ใน `~/.relic-scan` และเครื่องมือเปิดดูได้สามทาง ได้แก่ หน้าเว็บในเครื่อง เทอร์มินัล และ DuckDB

![หน้า Smart Scan ของบ้านเดโม: โดนัทแสดงแถว 3,173 แถว แยกเป็น tool calls, user text, AI text, tool results, thinking และ tool errors](images/C1-smart-scan-donut.png)

ภาพบนคือตัวอย่างของสิ่งที่ได้ เป็นหน้า Smart Scan ของบ้านเดโม แถวทั้งหมดในดัชนีแยกตามชนิด เล่มนี้ไม่มีภาพที่แต่งขึ้นนอกจากภาพปก

เล่มนี้พาเดินทีละขั้น จากติดตั้งไปจนถึงถามว่าเดือนนี้โมเดลไหนตอบไปกี่ครั้ง ใช้โทเคนเท่าไร ทุกคำสั่งในเล่มรันจริง ทุกภาพคือหน้าจอจริงของแอป

## ภาพมาจากไหน

ทรานสคริปต์จริงเป็นงานส่วนตัว จึงไม่มีสักบรรทัดอยู่ในเล่มนี้ ทุกภาพถ่ายจาก **บ้านเดโม** ที่สร้างด้วยสคริปต์ `make-demo-home.py` ในโฟลเดอร์ `book/` ข้างเล่ม เป็นทรานสคริปต์ 144 ไฟล์ของ repo สมมติหกตัว (tea-cart, starfish-api, harbor-bot, lantern-app, kite-docs, moss-cli) ข้อความ คำถาม คำตอบ และโมเดลทุกตัวแต่งขึ้น สคริปต์ใช้ seed คงที่ ใครรันก็ได้บ้านเดโมหน้าตาเดิม

ในแคปเจอร์ `~` จึงหมายถึงบ้านเดโมนั้น ไม่ใช่โฟลเดอร์ของใคร ส่วนภาพหน้าเว็บถ่ายจาก `relic-scan serve` ที่เปิดดัชนีเดโม ผ่าน Chrome แบบ headless ขนาด 1280 × 860

## วิธีอ่าน

- ภาค 1 ใช้งาน (บท 1–5): รันดัชนี เปิดหน้าเว็บ เปิดในเทอร์มินัล
- ภาค 2 อ่านดัชนี (บท 6–7): ถามด้วย DuckDB และเรื่องเดือนที่ปิดผนึก
- ภาค 3 ข้างใน (บท 8–9): chain ข้ามเครื่อง ความเป็นส่วนตัว
- ภาคผนวก (บท 10–11): รูปแบบของ transcript และโค้ดที่เลือก

แต่ละขั้นมีคำสั่งหรือหน้าจอ แล้วมีภาพของผลจริงอยู่ใต้มัน อ่านแค่ตัวหนังสือก็ทำตามได้ ภาพไว้ยืนยันว่าเห็นเหมือนกัน

## ใครเขียน

เล่มนี้เขียนโดย Claude ซึ่งเป็น AI กับ Nat คนที่เป็นเจ้าของโครงการ ภาพปกเป็นภาพเดียวที่ AI วาด ที่เหลือเป็นของจริงทั้งหมด

relic-scan เป็นโอเพนซอร์ส (AGPL v3) โค้ดอยู่ที่ https://github.com/Soul-Brews-Studio/relic4-scan หน้าเว็บของโครงการอยู่ที่ https://relic.buildwithoracle.com/scan/ เวอร์ชันที่ใช้ถ่ายทั้งเล่มคือ `26.10.26-alpha.516`
