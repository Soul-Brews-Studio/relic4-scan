Find and index every AI-agent transcript on this machine

Usage: relic-scan [COMMAND]

Commands:
  scan    Find every agent home (.claude, .claude_bak, .claudebak, .claude2, .codex …) and index …
  … its .jsonl files
  run     Incremental: scan, then parse only new/grown/rewritten files from where they were left, …
  … then meta + map
  up      One command: `run`, then serve the map and the tree on 127.0.0.1 …
  … (http://127.0.0.1:PORT/map · /tree)
  serve   Serve OUT/meta/map.html on 127.0.0.1: /map (star map) and /tree (homes -> repos -> …
  … sessions)
  export  Copy the sealed months and their seals to an S3-compatible store (AWS S3, Garage, …
  … MinIO); re-runnable, nothing is replaced unless --overwrite
  ops     What the relic chain is doing right now: the pass in flight with its stages and ETA, …
  … running processes, the hub, the S3 job
  seals   Closed months and their seals (read-only files with the time, rows and key hash they …
  … were sealed at); --verify checks each again
  log     The scan log: every index run and check (dry run) with what it found; --diff N lists …
  … one entry's files
  tui     Browse the sessions, repos and every .jsonl in the terminal (reads OUT/meta/*.parquet)
  meta    The month files + _state.tsv -> meta/files.parquet + meta/sessions.parquet (`run` does …
  … this as its last step)
  map     meta/sessions.parquet + meta/files.parquet -> meta/map.html: every session as a star, …
  … queryable in the browser
  parse   Parse every indexed file -> one Parquet file per Bangkok month (truth schema, copies …
  … folded)
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
